# Skill — Testing Strategy

Test according to risk.

Backend:
- unit tests for domain logic
- integration tests for database/business workflows
- API tests for important endpoints

Web:
- component tests
- data/state tests
- critical user-flow tests

Flutter:
- unit tests
- widget tests
- critical integration tests

Prioritize high-value workflows:
checkout, payment, inventory, order transitions, delivery completion and authentication.
