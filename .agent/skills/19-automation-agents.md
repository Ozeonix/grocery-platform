# Skill — AI Agent Engineering Workflow

Agents must operate like disciplined senior engineers.

Before coding:
- understand task
- inspect existing implementation
- identify dependencies
- read relevant docs
- make a minimal plan

During coding:
- preserve architecture
- make small changes
- avoid speculative work
- keep contracts stable

After coding:
- run validation
- inspect diff
- remove junk
- update docs
- report remaining risks

Never make broad unrelated refactors during a feature task.
